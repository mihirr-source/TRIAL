API Specification & Reference

All endpoints accept and return JSON over HTTP. Interactive schemas are hosted at: /docs (Swagger UI) · /redoc (ReDoc Spec)

// AUTHENTICATION PIPELINE HTTPONLY COOKIES

Session Management Endpoints

Stateful session management using signed HMAC SHA-256 cookies:

  • POST /api/auth/register — Register new account {"email", "name", "password"}
  • POST /api/auth/login — Log in with {"email", "password"}
  • POST /api/auth/logout — Log out and terminate session
  • GET /api/auth/me — Return authenticated user claims

// SEARCH API GET

GET /api/search?q=…&top_k=6

Hybrid semantic + lexical retrieval across English, Hindi, and Telugu. Returns matched primary standard, confidence score, and ranked alternatives.

// TENDER ANALYSIS POST

POST /api/analyze

Audit tender specification text (JSON payload: {"text": "…"}). Returns full compliance audit report with mandatory certifications, obsolete code warnings, and missing normative references.
