API Reference

All endpoints are JSON over HTTP. Interactive OpenAPI docs: /docs (Swagger UI) · /redoc

GET /api/health

Service status, catalogue version, sync mode and index stats.

{ "status": "ok", "catalog_version": "2026.09-seed-1",
  "sync": { "mode": "seed", "last_synced": "2026-09-29" },
  "stats": { "catalogue_size": 40, "alias_count": 362 } }

GET /api/search?q=…&top_k=6

Hybrid semantic + alias search. Multilingual queries supported (Hindi, Tamil in the seed vocabulary). Returns primary plus ranked alternatives with confidence scores and matched aliases.

curl "http://localhost:8002/api/search?q=cooling+unit+for+office"

POST /api/analyze

Full tender analysis. Body: {"text": "…"} (10–20,000 chars). Returns primaries with confidence, missing allied/normative standards, mandatory certification alerts, obsolete/unknown code flags, and a RAG health-check summary.

curl -X POST http://localhost:8002/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Supply of packaged drinking water in 20 L jars. TMT bars per IS 1786:2008."}'

GET /api/standards[?sector=electronics]

Browse the catalogue; filter by sector key (construction, electronics, appliances, water, food, safety).

GET /api/standards/{code}

One standard's detail: version, amendments, aliases, allied standards, certifications, spec pitfalls. Loose matching: IS 13252 resolves to IS 13252 (Part 1).

GET /api/certifications

All mandatory certification schemes mapped in the catalogue with the standards they apply to.

Data status: the engine runs on a curated seed catalogue for demo purposes. Before production use in any procurement workflow, replace it with a licensed/live BIS data feed and legal review of every recommendation.
