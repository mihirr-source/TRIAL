API Reference

All endpoints are JSON over HTTP. Interactive OpenAPI docs: /docs (Swagger UI) · /redoc

AUTH Authentication Endpoints

Session management via signed HttpOnly cookies:

  • POST /api/auth/register — Register new account {"email", "name", "password"}
  • POST /api/auth/login — Log in with {"email", "password"}
  • POST /api/auth/logout — Log out and clear session cookie
  • GET /api/auth/me — Get current authenticated user profile

GET /api/health

Service status, catalogue version, sync mode, retrieval mode and index stats.

{ "status": "ok", "catalog_version": "2026.09-seed-2",
  "retrieval_mode": "lexical",   // or "hybrid" with embeddings installed
  "sync": { "mode": "seed", "last_synced": "2026-09-29",
            "snapshot_records": 0 },   // "seed+snapshot" after an import
  "stats": { "catalogue_size": 84, "alias_count": 612 } }

GET /api/search?q=…&top_k=6

Hybrid semantic + alias search. Multilingual queries supported (English, Hindi, Tamil, Telugu vocabularies). Returns primary plus ranked alternatives with confidence scores and matched aliases.

POST /api/analyze

Analyze tender specification text (JSON payload: {"text": "…"}). Returns structured report with mandatory certifications, outdated code alerts, and missing normative references.

POST /api/analyze/file

Analyze tender PDF or DOCX file (multipart form data). Performs OCR / text extraction and standard verification.
